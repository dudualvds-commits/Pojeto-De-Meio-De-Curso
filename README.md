# 🎬 Projeto: [Universo One Day]

Este é o meu projeto de meio de curso de Desenvolvimento Web! Um site de 3 páginas desenvolvido com HTML5 e CSS3.

## 📌 Sobre o Projeto
[Um Site informativo e baseado na série One Day, feito de uma fã pra Fã e]

## 🛠️ Tecnologias Utilizadas
- HTML5 (Estrutura Semântica)
- CSS3 (Estilização, Background-image e Flexbox)
- Git & GitHub (Controle de versão e hospedagem)

## 📱 Páginas do Site
1. **Home (`index.html`):** Apresentação principal e destaques.
2. **História/Sobre (`historia.html`):** Detalhes, história ou tabela de serviços.
3. **Galeria (`galeria.html`):** Vídeo do YouTube incorporado e galeria de cards flexíveis.
