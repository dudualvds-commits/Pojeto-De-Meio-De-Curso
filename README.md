# 🎬 Projeto: Universo One Day

Este é o meu projeto de meio de curso de Desenvolvimento Web! Um site de 3 páginas desenvolvido com HTML5 e CSS3.

## 📌 Sobre o Projeto
O "Universo One Day" é um site dedicado a explorar a emocionante obra de David Nicholls, acompanhando a jornada inesquecível de Emma e Dexter ao longo de duas décadas. Escolhi esse tema por conta que eu sou extremamente fã da obra como um todo (filme,Série,Livro) permitindo criar uma experiência interativa entre o livro, o filme e a adaptação em série.

## 🛠️ Tecnologias Utilizadas
- HTML5 (Estrutura Semântica limpa com tags modernas)
- CSS3 (Estilização personalizada, Gradientes, Flexbox e Responsividade via Media Queries)
- Git & GitHub (Controle de versão e hospedagem)

## 📱 Páginas do Site
1. **Home (`index.html`):** Apresentação principal, sinopse e destaques da obra.
2. **História (`historia.html`):** Detalhes, premissas, diferenças entre os formatos (livro, filme e série) e biografia do autor.
3. **Galeria (`galeria.html`):** Trailers oficiais do YouTube incorporados, vídeos de análises críticas e galeria estilizada com cards flexíveis de imagens.
